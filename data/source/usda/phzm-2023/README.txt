2023 USDA Plant Hardiness Zone Map Mean Annual Extreme Low Temperature Rasters

Each folder (Alaska, Contiguous, Hawaii, Puerto Rico) contains a TIFF raster file and sidecar files containing geographic data and metadata. Each TIFF file provides the estimated 30 year average of annual extreme minimum low temperatures for the period 1991 to 2020 for the corresponding geographic region at a resolution of approximately 800 meters. This data was compiled by the PRISM Climate Group at Oregon State University by applying an interpolating algorithm that accounts for altitude, topography, and other factors to data from more than 1,000 weather stations. Note that temperatures are recorded in 100ths of degrees Fahrenheit; a raster value of 1255 would thus represent a temperature of 12.55 degrees Fahrenheit.
Each TIFF has an associated metadata file (ending “.tif.xml”) that contains more complete metadata.
These rasters were used in several ways to create the USDA Plant Hardiness Zone Map and associated web site (https://planthardiness.ars.usda.gov/). For purposes of display, the rasters are typically classified into 26 “half-zones” (designated 1a to 23b) that each represents a 5 degree temperature band ranging from -60 degrees to 70 degrees. Each half zone is assigned a unique color when the rasters are displayed on interactive maps on the Plant Hardiness Zone Map website and on static maps that are produced for each region and for each US state. 
The following publication provides a detailed description of the methodology used to create these rasters. While the publication relates to the 2012 version of the Plant Hardiness Zone Map, the same general methodology was used to create the 2023 data.
Daly, C., M.P. Widrlechner, M.D. Halbleib, J.I. Smith, and W.P. Gibson. 2012. Development of a new USDA Plant Hardiness Zone Map for the United States. Journal of Applied Meteorology and Climatology, 51: 242-264.
