# Mid-Atlantic cultivar source snapshots

These files are commodity sections from the **2026/2027 Mid-Atlantic
Commercial Vegetable Production Recommendations**, published by Rutgers NJAES
Cooperative Extension with cooperating land-grant universities and USDA.

Source landing page:
https://njaes.rutgers.edu/pubs/publication.php?pid=E001

Retrieved: 2026-08-08

The publication states that its recommendations are for commercial vegetable
growers rather than specifically for home gardeners. Kitchen Almanac retains
that scope in the staged source metadata. Cultivar inclusion is evidence that a
named variety appears in the regional table; it is not, by itself, a
personalized recommendation for a home garden.

Checksums and exact source URLs are recorded in
`../staged-mid-atlantic.v1.json`. The publication's pesticide material is not
ingested into Kitchen Almanac's cultivar catalog. Run
`kitchen-almanac cultivars fetch` to create the locally retained PDF snapshots;
the copyrighted binaries are excluded from version control.
